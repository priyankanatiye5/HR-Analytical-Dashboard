# HR-Analytical-Dashboard
1. An interactive HR Analytics Dashboard in Power BI to analyze employee workforce data and identify patterns related to employee attrition. The dataset consisted of structured employee-level records including employee demographics, job roles, department, age, education, salary, joining date, and attrition status.

2. Tech Stack.
 The dashboard was built using the following tools and technologies:
📊 Power BI Desktop – Main data visualization platform used for report creation.
• 📂 Power Query – Data transformation and cleaning layer for reshaping and preparing the data.
• 🧠 DAX (Data Analysis Expressions) – Used for calculated measures, dynamic visuals, and conditional logic.
• 📝 Data Modeling – Relationships established among tables (resorts, snow, and data_dictionary) to enable cross-filtering and aggregation.
• 📁 File Format – .pbix for development and .png for dashboard previews.

4. Data Source
 Source: YouTube Data Tutorial 
The dataset consists of approximately 1,500 employee records from a single organization. Each row represents an individual employee, and the dataset contains structured attributes covering demographics, job-related details, performance indicators, and attrition status.

5. Highlights
• Goal of the Dashboard To deliver an interactive visual tool that Enables users to identifies key drivers of employee attrition by analyzing turnover across departments, age groups, overtime exposure, job satisfaction levels, and tenure, enabling HR to implement targeted retention strategies..
